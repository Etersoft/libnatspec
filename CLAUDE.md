# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

libnatspec ("Nation Specifity Library") is a C library (LGPL 2.1) that answers "which charset does this locale use, here and on other systems (Windows/DOS/Mac)?" and converts strings between them. It is used by patched tools (mount, mkisofs, unzip, zip, samba — see `examples/*.patch`) to pick correct filename/codepage options. Packaged primarily for ALT Linux via gear (`.gear/rules`, `libnatspec.spec`).

## Build and test

Autotools project (generated files like `configure`, `Makefile.in` are gitignored):

```sh
./autogen.sh                 # autoreconf -fiv + configure --enable-maintainer-mode --with-debug --with-python CFLAGS="-Werror -pedantic"
# or manually:
autoreconf -fiv && ./configure --with-debug
make
make check                   # all tests in tests/
make -C tests check TESTS=test_convert   # single test; output in tests/test_convert.log
make distcheck               # verifies VPATH build and tarball completeness
```

Sanitizer run: `./configure CFLAGS="-g -O1 -fsanitize=address,undefined" LDFLAGS="-fsanitize=address,undefined" && ASAN_OPTIONS=detect_leaks=0 make check`.

### Tests (`tests/`)

- C tests use `tests/check.h` (`CHECK`, `CHECK_INT`, `CHECK_STR`, `CHECK_STR_FREE`), which reports every failed check and ends with `return check_done();`. Exit code 77 means skip.
- `test_*` programs must pass. `xfail_*` programs hold **known, unfixed bugs** and are listed in `XFAIL_TESTS`. When you fix a bug, move its checks into a `test_*` program (or move the program to `PASS_TESTS`); otherwise the test reports XPASS and `make check` fails.
- Tests set and clear `LC_ALL`/`LC_CTYPE`/`LANG`/`G_FILENAME_ENCODING` themselves, so they don't depend on your environment. Without `setlocale()` the fallback charset is `ANSI_X3.4-1968`.
- `test_env` and `test_i18n` are linked with `lib/*.c` directly. `i18n_get_locale.c` rebuilds `get_locale.c` so that the system i18n file comes from `$NATSPEC_TEST_I18N_FILE`.
- Fuzzing (libFuzzer, needs clang): after `./configure`, `tests/fuzz/build.sh [BUILDDIR]` builds `BUILDDIR/fuzz/fuzz_*` with ASan/UBSan (`fuzz_cli` runs `src/natspec.c` main with fuzzed argv, only with popt); `tests/fuzz/run.sh [BUILDDIR [SECONDS]]` runs each one (`0` only replays the seed corpus in `tests/fuzz/corpus/NAME`). Add a seed there for every crash you fix.
- `test_cli.sh` is skipped if `natspec` was built without popt, and `test_python.sh` is skipped without `--with-python` or in sanitizer builds.
- configure options: `--with-python` (SWIG binding in `src/python`), `--with-doxygen` (API docs in `docs/`), `--with-debug`, `--with-i18n-file=FILE[:FILE...]` (system-wide LANG source, default `/etc/locale.conf:/etc/sysconfig/i18n`, first file with LANG wins).
- Builds with `-Wall -funsigned-char`; autogen adds `-Werror -pedantic`, so keep code warning-free.
- Depends on iconv (required) and popt (optional, for the `natspec` CLI).
- Release: tag `X.Y.Z` (upstream) next to ALT tags `X.Y.Z-altN`; `./release.sh [tag]` makes `../libnatspec-X.Y.Z.tar.gz` with generated `configure` via `make distcheck` — publish it on GitHub Releases so distributions build without autotools. The version is kept in both `libnatspec.spec` and `AC_INIT` in `configure.ac` — bump them together.
- Reference built libraries as `$(top_builddir)/lib/libnatspec.la` and list every header in `*_SOURCES`, otherwise `make distcheck` breaks.

## Layout and architecture

- `lib/` — `libnatspec.so`. Public API in `lib/natspec.h` (all `natspec_*` functions); internal helpers/macros (`_n_bsearch`, `_n_isempty`, `struct charsetrel_entry`) in `lib/natspec_internal.h`, which requires `config.h`.
  - `get_locale.c` — determine current/user/system locale (env vars, then the i18n file).
  - `get_charset.c` — locale → charset lookup for `NATSPEC_UNIXCS/WINCS/DOSCS/MACCS` using the `charset_relation` table.
  - `filesystem.c` — charset → codepage / Linux kernel NLS name (`data/charset_names.h`).
  - `enrich_fs_options.c` — adds `iocharset=`/`codepage=` etc. to mount options per filesystem type.
  - `convert.c` — iconv wrappers and transliteration to 7-bit (`unicode/uni_7b.h`).
- `libhi/` — experimental `libnatspechi` (language names); configured but **not** in top-level `SUBDIRS`, so not built by default.
- `src/natspec.c` — `natspec` command-line tool; `src/python/` — SWIG binding: `natspec_wrap.c` and `natspec.py` are generated by `swig -python natspec.i` and committed; regenerate them after changing `natspec.h`.
- `profile/` — shell snippets installed to set locale env vars.

### Generated data tables (do not hand-edit casually)

- For a locale whose charset has no exact row (`be_BY.CP1251`), the UNIX charset comes from the locale name and WIN/DOS/MAC from the `language_TERRITORY[@modifier]` row, so rows are needed per territory, not per charset variant.
- `lib/data/get_charset_data.h` is generated by `lib/data/gen_data.sh`, which runs the WINE program `print_data_string.exe.so` (build with `make -C lib/data`, needs `winegcc`) for every `locale -a` entry. Regenerating therefore depends on the locales installed on the host.
- Lookups use `bsearch` with `strcmp` on the first column, so **arrays in `lib/data/*.h` and `lib/unicode/uni_7b.h` must stay sorted by their first field** (the generator sorts with `LC_ALL=C`). Manual changes of Windows/DOS/Mac charsets go to `lib/data/charset_overrides.txt` (with the source of each value, e.g. Microsoft NLS API Reference); `gen_data.sh` applies them via `apply_overrides.sh`, and `tests/test_data_overrides.sh` fails if the committed table lacks them. Never hand-edit rows of `get_charset_data.h` directly.
- `lib/unicode/uni_7b.h` is generated by `lib/unicode/gen-7b` from `7bitrepl.lnx`.

## Gotchas

- `lib/get_charset.c` and `tests/test_get_charset.c` are ISO-8859 encoded, not UTF-8 — use `grep -a` and preserve the encoding when editing.
- Library functions returning `char *` return malloc'ed strings the caller must free; `const char *` returns point to static table data.
